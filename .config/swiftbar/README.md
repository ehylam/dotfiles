# SwiftBar

Point SwiftBar at:

```sh
~/.dotfiles/.config/swiftbar/plugins
```

Plugins:

- `ai-sessions.15s.sh`: herdr agents ordered by attention (blocked, done, working, idle; click to focus the workspace) and AI CLI process visibility.
- `browser-qa.1m.sh`: Safari/iOS QA readiness and quick test actions.
- `dev-servers.20s.sh`: local dev server process and port visibility.
- `workday-timer.1m.sh`: focused workspace timer and time-note copy action.
- `ai-cleanup.30s.sh`: manual cleanup shortcuts.
- `sleep-toggle.10s.sh`: menu-bar toggle for `caffeinate -dimsu`.
